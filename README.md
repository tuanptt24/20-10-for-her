# Website 20/10 dành riêng cho Cdang

## Xem thử
Mở `index.html` bằng Chrome hoặc Edge.

## Hiệu ứng bất ngờ khi bấm “Mở lá thư”
Khung ảnh từ từ hạ xuống như một chiếc đèn lồng, dừng lại, rồi website tự cuộn đến bức thư.

### Thêm ảnh của Cdang
1. Đổi tên ảnh thành `cdang-photo.jpg`.
2. Đặt file ảnh cùng thư mục với `index.html`.
3. Tải cả `index.html` và `cdang-photo.jpg` lên repository GitHub ở thư mục gốc.
4. Mở website và thử bấm “Mở lá thư”.

Nếu chưa thêm ảnh, khung sẽ hiện lời nhắc thay cho ảnh. Nên chọn ảnh dọc, rõ nét; hãy cân nhắc quyền riêng tư trước khi đăng ảnh lên website công khai.

## Xuất bản bằng GitHub Pages
1. Tải `index.html` lên repository công khai.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, rồi **Save**.
4. Khi website đã được xuất bản, thêm `cdang-photo.jpg` vào cùng thư mục gốc nếu muốn hiện ảnh.


## Hiệu ứng “Một chút yêu thương nữa” — 4 ảnh ở bốn góc
Bấm nút ở cuối trang sẽ làm 4 khung ảnh xuất hiện ở bốn góc màn hình, đung đưa nhẹ trong khoảng 12 giây. Chúng không phủ lên vùng nội dung chính ở giữa và không chặn thao tác vì lớp ảnh không nhận click.

### Thêm 4 ảnh
Đặt tối đa 4 ảnh cạnh `index.html`, đặt tên chính xác:
- `cdang-photo-1.jpg` — góc trên trái
- `cdang-photo-2.jpg` — góc trên phải
- `cdang-photo-3.jpg` — góc dưới trái
- `cdang-photo-4.jpg` — góc dưới phải

Tải các ảnh lên cùng thư mục gốc GitHub Pages như `index.html`. Nếu thiếu ảnh, khung tương ứng vẫn hiện với lời nhắc trang trí. Trên điện thoại, ảnh được thu nhỏ để chừa vùng giữa dễ đọc.
